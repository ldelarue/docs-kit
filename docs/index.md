# docs-kit

Documentation for docs-kit.

This site is generated and maintained with **docs-kit**: the reference pages
below are regenerated with `mise run docs:refresh`, everything else is
hand-written Diátaxis content.

- **[CLI reference](references/cli/docs-kit.md)** — commands, flags and
  exit codes rendered from the committed usage spec.
- **Tutorials / Guides / Explanation** — write these by hand, one Diátaxis
  type per page.
